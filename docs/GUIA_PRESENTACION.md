# Guía rápida de presentación

1. Mostrar la portada y explicar que el estudiante no necesita iniciar sesión.
2. Entrar a Estudiante y filtrar por Matemática → Razonamiento matemático.
3. Abrir un tema, responder las 3 preguntas y mostrar el puntaje.
4. Descargar la ficha en texto.
5. Iniciar sesión como Docente y demostrar Registrar, Buscar, Editar y Eliminar.
6. Iniciar sesión como Administrador y mostrar gestión de docentes y estadísticas.
7. En MySQL Workbench, mostrar las tablas: usuarios, niveles, areas, subareas, materiales y retos_evaluaciones.

Arquitectura: **React SPA → API REST Node/Express → MySQL**.
