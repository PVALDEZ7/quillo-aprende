# Requisitos cubiertos

| Requisito del documento | Implementación |
|---|---|
| RF01 Header, Footer y Menu sin recargas | React SPA con componentes reutilizables |
| RF02 Accesos a Estudiante y Docente | Menú y portada; se incluye Administrador |
| RF03 4 niveles y 2 áreas | Iniciación, Básico, Intermedio y Avanzado; Matemática y Comunicación |
| Aplicaciones solicitadas | Razonamiento matemático, Aritmética, Razonamiento verbal y Literatura |
| RF04 Catálogo con Tarjetas | `Tarjeta.jsx` |
| RF05 Reto de 3 preguntas y puntaje | Modal interactivo + banco en MySQL |
| RF06 Fichas descargables | Archivo `.txt` generado desde cada material |
| RF07 Registrar | Formulario + POST API |
| RF08 Buscar y Filtrar | Palabra clave, nivel, área y subárea |
| RF09 Editar | Formulario precargado + PUT API |
| RF10 Eliminar | Baja lógica + DELETE API |
| RF11 Autenticación | Contraseña con scrypt + token HMAC + roles |
| RF12 React ↔ MySQL | Fetch asíncrono → Express → mysql2 |
